# ⚡ আমার টুলকিট (Pixel 7 Pro)

তোমার ফোনের জন্য ২১টা টুল একটা অ্যাপে।

## কীভাবে ফোনে চালাবে
1. কম্পিউটারে **Android Studio** নামাও: https://developer.android.com/studio
2. এই zip খুলে Android Studio-তে **File → Open** দিয়ে `AmarToolkit` ফোল্ডার খোলো। প্রথমবার কিছুক্ষণ সময় নেবে (ইন্টারনেট লাগবে)।
3. ফোনে **Developer options** চালু করো: Settings → About phone → **Build number**-এ ৭ বার চাপো।
4. Settings → System → Developer options → **USB debugging** চালু করো।
5. USB দিয়ে ফোন লাগাও, ফোনে "Allow" চাপো।
6. Android Studio-তে উপরে সবুজ ▶️ **Run** চাপো। অ্যাপ ফোনে ইনস্টল হয়ে যাবে।
7. অ্যাপ খুলে প্রথমে **⚙️ অনুমতি সেটআপ** থেকে অনুমতিগুলো দাও।

## যেগুলো বাদ দিয়েছি (Android করতে দেয় না বা খুব জটিল)
অন্য অ্যাপ লুকানো, পকেটে টাচ বন্ধ, নিজে থেকে কীবোর্ড বদল, Wi-Fi/ডেটা/ব্লুটুথ সরাসরি বন্ধ, ক্লিপবোর্ড ইতিহাস, ডার্ক মোড বদলানো, চোরের ছবি তোলা, মুখ দেখে মুড বোঝা, তালি দিয়ে খোঁজা, আবহাওয়া ওয়ালপেপার ইত্যাদি।

## টিপস
- ফোনের স্ক্রিন বন্ধ থাকলে ঝাঁকি/উল্টানো সবসময় ধরা নাও পড়তে পারে। এটা Android-এর ব্যাটারি বাঁচানোর নিয়ম।
- নোটিফিকেশনে "আমার টুলকিট চালু আছে" দেখাবে। এটা থাকলেই পটভূমির ফিচার চলে।
- কোনো এরর এলে Android Studio-র নিচের **Build** ট্যাবের লেখা কপি করে আমাকে পাঠাও।
